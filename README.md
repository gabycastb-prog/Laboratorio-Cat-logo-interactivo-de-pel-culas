
Este es mi laboratorio de React: un catálogo de películas al estilo Netflix.

En la página puedes buscar películas por su nombre, filtrarlas por género, año o calificación, ver la información completa de cada una, guardar tus favoritas y darles de 1 a 5 estrellas.

Lo hice con React, Vite y Tailwind CSS.

Hecho por Hanna Gabriela Castaño Beltrán.

## Cómo abrirlo en tu computador

1. Descarga el proyecto: git clone []
2. Entra a la carpeta:cd catalogo-peliculas
3. Instala lo necesario:npm install
4. Ábrelo:npm run dev
5. Entra en el navegador a http://localhost:5173
